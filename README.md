# GIGS

V1 foundation for a cooperative household and community services platform.

## Run locally

Open `index.html` in a modern browser, or serve this folder with any static web server. No dependencies or build step are required.

## Structure

- `src/data` — service/provider data and translation dictionary
- `src/components` — reusable UI primitives
- `src/styles` — responsive design system
- `src/app.js` — route views and booking flow
